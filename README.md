# 樂動音樂教室 — 台灣音樂補習班 APP（原型）

參考專案內 6 張圖片的功能架構，改為台灣在地化版本：繁體中文、民國日期、NT$、LINE 通知、台灣支付與電子發票。

## 啟動

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 產出 dist/
```

資料存在瀏覽器 localStorage，可在「設定 → 還原示範資料」重置。右上角「校長 ⇆」可切換 校長／老師／學生家長 三種身分。

## 功能

| 區塊 | 頁面 |
|---|---|
| 管理（校長／老師） | 學生管理、班級管理、老師管理（鐘點費試算）、課程管理、堂數點名（自動扣堂＋LINE 通知）、排課約課（衝堂檢查、國定假日提示）、財務中心、收銀台（LINE Pay／街口／台灣Pay／信用卡、電子發票載具與統編）、潛在學生跟進、續費提醒、數據中心 |
| 教學／學習 | 成長檔案、雲端空間、樂譜庫（簡譜＋試聽）、音樂百科（含台灣音樂家）、視唱練耳、樂理練習題（YAMAHA／ABRSM）、鋼琴與爵士鼓模擬器、節拍器與音階、AI 節奏陪練、作品秀場、積分兌換、音樂寵物、練琴打卡 |
| 拓展 | 招生工具（揪團、早鳥、體驗課、推薦有禮、營隊，分享到 LINE）、賽事活動、推薦分潤商城、對外課程型錄 |

## 技術

React 19 + TypeScript + Vite，無後端；音效用 Web Audio API 即時合成。

## 正式上線前需要串接

- LINE Messaging API／LIFF（目前推播只記錄在「訊息」頁）
- 金流（LINE Pay、街口、綠界或藍新）與電子發票加值中心（目前付款 QR Code 與發票號碼為示範）
- 後端資料庫與帳號登入、雲端檔案儲存
